# DL Query

A [Protégé](https://protege.stanford.edu/) plugin that provides an interface for querying OWL ontologies using the active reasoner.

The `5.x` development line targets Protégé 6 and OWL API 5. Build and run the tests with Java 11 or later:

```shell
mvn --batch-mode clean verify
```

The [user guide](https://protegewiki.stanford.edu/wiki/DLQueryTab) is available on the Protégé Wiki.
